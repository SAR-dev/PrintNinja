## Default Permission

Default permissions for the Android print plugin

#### This default permission set includes the following:

- `allow-html-to-pdf`
- `allow-enumerate-usb-printers`
- `allow-test-printer`
- `allow-start-background-service`
- `allow-stop-background-service`
- `allow-is-background-service-running`
- `allow-request-battery-exemption`
- `allow-is-battery-exemption-granted`
- `allow-notification-permission-state`
- `allow-request-notification-permission`
- `allow-local-network-permission-state`
- `allow-request-local-network-permission`
- `allow-open-local-network-settings`

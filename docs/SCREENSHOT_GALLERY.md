# 🖼️ Screenshot gallery

A visual tour of PrintNinja in English, light theme, on a 1440 × 900 Windows desktop and a Pixel 7-sized Android phone. The images are generated by `pnpm shots:gallery`; regenerate and commit them after an intentional UI change. They are for design review, not a replacement for the automated checks in [`e2e/tests/`](./../e2e/tests/).

**Note:** the capture has no Rust print engine, so the Designer and Print previews in these shots are approximations: document templates use real HTML/CSS with placeholders filled by sample data (no Handlebars helpers), and label templates are painted onto an offscreen canvas from their scene elements. Neither matches the desktop app's Rust renderer pixel for pixel. See the [screenshot script notes](./SCREENSHOTS.md#notes) for details.
